# FF Aim Trainer (Android)

Standalone Android aim-training mini-game with a neon-blue UI. It does not connect to Free Fire, read game memory, overlay the game, or automate input in another app.

## Features
- Moving target and tap-to-hit scoring
- Finger-controlled crosshair
- Adjustable FOV circle
- Adjustable target speed
- Restart and pause controls
- Android 6.0+ (minSdk 23)

## Build APK
1. Install Android Studio (current stable) with Android SDK Platform 35.
2. Open this `FFAimTrainer` folder in Android Studio.
3. Allow Gradle sync to finish.
4. Select **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
5. Android Studio shows the generated APK path, normally `app/build/outputs/apk/debug/app-debug.apk`.

No signing key is required for a debug APK. To publish or distribute a release build, create a release signing key in Android Studio.
